# 🦋 Детский клуб «Стрекоза»

Проект представляет собой современный адаптивный сайт клуба с информацией об услугах, ценах, мероприятиях и возможностью оставить заявку.

## 📋 Возможности

* 🏠 Главная страница клуба
* 🎈 Информация об услугах и направлениях
* 💳 Абонементы и цены
* 🎉 Бронирование праздников
* 📸 Галерея
* 📍 Контактная информация и карта
* 📝 Форма обратной связи
* 📱 Адаптивная верстка для мобильных устройств, планшетов и ПК
* 🪟 Модальные окна для отправки заявок
