# Strekoza — Landing Page

Modern responsive website for the children's club "Strekoza". The website provides information about the club, its services, activities and offers an easy way for parents to get in touch and submit an application.

## Features

- Information about services and activities
- Membership plans and pricing
- Holiday and event booking
- Photo gallery
- Contact information and location map
- Contact and application form
- Modal windows for submitting applications
- Responsive design for mobile devices, tablets and desktops
- Responsive navigation with mobile menu
- Modern and child-friendly visual design
